# Participation ratio flags some degenerate representations, but does not reliably rank healthy encoders

Code and results for a paper submitted to **ESANN**.

The geometry of a frozen representation is often offered as a label-free way to
pick an encoder, on the premise that a measure correlated with downstream
accuracy can rank candidates. This work tests that premise on seventeen frozen
encoders across four domains.

**Main result.** The participation ratio does correlate with linear-probe
accuracy (ρ = 0.41, p = 0.007), but the correlation comes from the checkpoints
of extreme dimensionality: it drops to 0.27 without MAE, to 0.21 without the
two CLIP as well, and sits at 0.11 across the nine architectures. A held-out
checkpoint, with the prediction registered before measurement, shows where the
premise fails: BEiT-3 probes close to the bottom of the seventeen — only MAE
probes worse on DTD, Pet and SUN397 — yet the ratio flags it in only one of the
four domains.

## Method, in brief

- **Participation ratio** is `(Σλ)² / Σλ²` over the eigenvalues of the
  covariance of the pooled feature maps. It is not Roy and Vetterli's entropic
  effective rank, which is a different quantity; `representation.py` computes
  the ratio and says so explicitly.
- **Intervals** come from subsampling *without* replacement at m = n/2 = 100
  over 200 images (`ci_sub`). A duplicated image adds no direction to a
  covariance, so a bootstrap with replacement would put the point estimate
  outside its own interval. The rank ceiling at m = 100 is therefore 99, not
  199.
- **The probe** is a logistic regression over the same frozen features, with
  5 outer folds and C chosen by 3 inner folds, averaged over seeds 0, 1 and 2.
  On mammography the folds are `StratifiedGroupKFold` **by patient** (103
  patients across 387 images), and the bootstrap resamples patients, not
  images.
- **Inference** is a permutation at the **encoder** level: one permutation is
  applied to all four domains, preserving each encoder's profile across
  domains. With k encoders the smallest reachable p is about 1/k!.
- **The width control** is a partial correlation with conditional inference by
  Freedman–Lane (`partial_fl.py`), which preserves the width–probe association
  the conditional null must keep. It supersedes the joint permutation in
  `partial.py`.
- **A held-out encoder** is reported by how many of the seventeen reference
  encoders probe worse than it, never by a rank inside a pool it was not part
  of.

## Data

The image samples are **not** in this repository.

- **INbreast** (mammography) requires registration with the dataset authors
  and may not be redistributed. The derivative tables this code reads
  (`inbreast_images.csv`, `inbreast_boxes.csv`) contain patient identifiers and
  are likewise not included.
- **DTD**, **Oxford-IIIT Pet** and **SUN397** have their own licences and are
  not redistributed here either. `code/download_datasets.py` rebuilds the
  sample from public Hugging Face mirrors: 387 images per dataset, the same N
  as mammography, so that "what kind of data" is not confounded with "how much
  data".

## Requirements

Python 3.10+, with `torch`, `timm`, `torchvision`, `scikit-learn`, `scipy`,
`numpy`, `pandas`, `pillow`, `matplotlib` and `huggingface_hub`. A GPU is
needed to re-run the measurements; the analyses in `results/` can be
regenerated from the committed JSON on CPU alone.
